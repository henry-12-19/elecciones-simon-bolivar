Sistema Electoral Simón Bolívar

Paquete completo para GitHub Pages (votación, administración y observación).

1. Antes de actualizar

Cierra la elección, exporta el acta y guarda respaldo de los resultados y del repositorio actual. Nunca subas archivos con cédulas, contraseñas ni secretos privados.

2. Base de datos Supabase

Si todavía NO aplicaste la modalidad de voto libre, revisa y ejecuta en Supabase → SQL Editor el archivo ACTUALIZAR-SUPABASE-VOTO-LIBRE.sql una sola vez y con la elección cerrada. Si ya lo aplicaste y el sistema vota sin identificación, no vuelvas a ejecutarlo. No ejecutes database.sql de instalación inicial.

3. GitHub

  1. Abre el repositorio elecciones-simon-bolivar y descarga un respaldo de la versión anterior si la necesitas.
  2. Sube o sustituye los archivos index.html, admin.html, observador.html, styles.css, voter.js, app.js, observer.js, config.js.
  3. Dentro de assets coloca logo.png, lista-a.webp y lista-b.webp. Si la carpeta no existe, créala desde GitHub con assets/README.txt y luego sube las imágenes entrando en la carpeta.
  4. Confirma con Commit changes sobre main. No subas la carpeta contenedora como subcarpeta: los HTML deben quedar en la raíz del repositorio.
  5. Revisa Settings → Pages → Branch main y carpeta /(root).
  6. Al terminar la publicación, fuerza la actualización con Ctrl + Shift + R.

5. Comprobaciones

  1. Revisa que aparezcan el logotipo y las dos fotos: Lista A = bandera roja; Lista B = bandera azul.
  2. Comprueba que «Ingresar a votar» abra la papeleta (solo cuando la elección esté abierta).
  3. Registra un voto de prueba, verifica que solo aumente una unidad en el conteo y que a los 5 segundos vuelva al inicio.
  4. Comprueba que administración requiera la cuenta de propietario, que observación requiera la cuenta docente, y que el docente no pueda guardar cambios.
  5. Prueba la emisión desde dos equipos distintos y valida el conteo.
  6. Guarda un respaldo de las pruebas antes de reiniciar votos.
Limitación de voto libre: sin padrón ni identificación, no es posible garantizar un único voto por persona. Supabase contará papeletas emitidas, no votantes únicos. Usa supervisión presencial, controla físicamente el acceso a los equipos y no publiques el enlace de votación de forma abierta para una elección oficial sin medidas adicionales. La página usa una clave publicable, no una clave secreta.
